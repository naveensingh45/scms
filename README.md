# Student Complain Management System

A simple web app where students can submit and track complaints, and admins can manage and resolve them.

Built with **Python Flask**, **SQLite**, and **Bootstrap** as a Software Engineering lab project.

---

## Setup

```bash
git clone https://github.com/naveensingh45/scms.git
cd scms
pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000`

---

## Features

- Student: register, submit complaints, track status
- Admin: view all complaints, update status, add remarks
- Status flow: `Submitted → In Progress → Resolved`
